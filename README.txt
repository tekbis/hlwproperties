H.L.W. Properties — Modern Netlify Edition

UPLOAD
1. Unzip this archive.
2. Drag the folder containing index.html into Netlify Drop.
3. Enable form detection in Netlify Forms, then redeploy the folder if needed.
4. Submit a test inquiry after deployment. Configure email notifications in Netlify Forms with the business email.
